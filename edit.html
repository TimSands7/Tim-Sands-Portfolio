Projects

    The order here is the order on your home page.

    Publish your changes

    1. Click Copy my changes.
    2. Click Open projects.js on GitHub. It opens the file ready to edit.
    3. Click inside the file, select everything (Ctrl+A, or ⌘+A on a Mac) and paste (Ctrl+V / ⌘+V).
    4. Click Commit changes…, then Commit changes again.

    Your site updates within a couple of minutes. Your edits stay saved in this browser, so you can keep editing afterwards.

    Open projects.js on GitHub

    Prefer a file? . If your browser saves it as “projects (1).js”, rename it to exactly projects.js before uploading, or GitHub adds it as a separate file that the site ignores.
